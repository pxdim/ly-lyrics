# LY 歌詞顯示系統 -- 使用者手冊

> 適用版本：2.0 | 最後更新：2026-03-19

LY 是一套即時歌詞投影系統，專為教會敬拜、演唱會、團契聚會等場合設計。操作者在「控制台」選歌、切換歌詞，投影端（「顯示端」）即時同步呈現。本手冊將帶你從零開始，一步步學會所有功能。

## 1. 快速開始（5 分鐘上手）

### 你需要準備什麼

- **任何有瀏覽器的裝置**：電腦、平板、手機都可以（建議使用 Chrome）
- **同一個網路環境**：控制台和投影端需要在同一個網路下
- **投影設備**（選用）：投影機或外接螢幕，用來顯示歌詞給會眾看

### 最簡流程

```
控制台（你的電腦/手機）          顯示端（投影電腦）
        │                              │
   ①  開啟控制台                        │
        │                              │
   ②  記下 6 碼同步碼           ③  開啟顯示端
       (例如 A3X9K2)                    │
        │                     ④  輸入同步碼 → 連線成功
        │                              │
   ⑤  選擇歌曲                ⑥  投影端即時顯示歌詞
        │                              │
   ⑦  按方向鍵/點擊切換歌詞    ⑧  投影端同步更新
```

**具體步驟：**

1. **開啟控制台**：在你的裝置上打開瀏覽器，前往 `https://你的網址/controller`
2. **記下同步碼**：畫面頂端會顯示一組 6 碼英數字同步碼（例如 `A3X9K2`），這是你的「房間號碼」
3. **開啟顯示端**：在投影電腦上打開瀏覽器，前往 `https://你的網址/display`
4. **輸入同步碼**：在顯示端輸入剛才的 6 碼同步碼，輸入完畢會自動連線
5. **選擇歌曲**：回到控制台，在左側歌曲庫點選要投影的歌曲
6. **切換歌詞**：按鍵盤方向鍵或點擊歌詞行，投影端會同步顯示

> **更快的方式**：在控制台點擊「複製連結」按鈕，把連結傳給投影端電腦直接開啟，不用手動輸入同步碼。

## 2. 控制台操作

控制台是你操作歌詞的主要介面。根據你使用的裝置，畫面會自動調整為不同的版型。

### 2.1 桌面版畫面（電腦，1280px 以上）

桌面版分為四個區域：

```
┌─────────────────────────────────────────────────────────┬───────┐
│  狀態列：房間碼 ∙ 連線狀態 ∙ 裝置數量 ∙ 當前歌曲       │       │
├──────────┬────────────────────┬──────────────────────────┤       │
│          │                    │ 即時預覽                 │  QR   │
│  歌曲庫  │   歌詞操作區       │ (模擬投影畫面)           │  Code │
│ /播放清單│   (Cue Grid)       ├──────────────────────────┤       │
│          │                    │ AI 追蹤 / 顯示設定       │       │
├──────────┴────────────────────┴──────────────────────────┴───────┘
```

- **左欄 - 歌曲庫 / 播放清單**：瀏覽、搜尋、新增歌曲，或管理播放清單
- **中欄 - 歌詞操作區（Cue Grid）**：顯示當前歌曲的所有歌詞行，點擊任一行可跳轉
- **右上 - 即時預覽**：一個小的 16:9 畫面，模擬投影端實際看到的效果
- **右下 - AI 追蹤 / 顯示設定**：調整投影端的字體大小、顏色、背景等
- **最右 - QR Code**：讓投影端掃碼快速連線

> **提示**：每個區域的寬度可以拖曳邊界來調整。

### 2.2 平板版畫面（768px - 1279px）

平板版分為兩欄：

- **左側**：歌曲庫 / 播放清單
- **右側**：AI 追蹤面板 + 歌詞操作區

### 2.3 手機版畫面（768px 以下）

手機版使用底部分頁切換，共有四個分頁：

| 分頁 | 功能 |
|------|------|
| **歌曲** | 瀏覽歌曲庫 / 播放清單 |
| **歌詞** | 操作歌詞行（Cue Grid） |
| **設定** | AI 追蹤開關 + 顯示設定 |
| **QR** | 顯示 QR Code + 複製連結 + 產生新房間碼 |

### 2.4 頂部狀態列

狀態列位於畫面最上方，顯示以下資訊：

| 項目 | 說明 |
|------|------|
| **Room 同步碼** | 點擊可複製 6 碼同步碼 |
| **複製連結** | 複製帶有同步碼的顯示端網址，分享給投影端 |
| **新房間** | 產生新的同步碼（注意：所有已連線的顯示端需要重新連線） |
| **QR 按鈕** | 顯示 QR Code（平板/手機版） |
| **SYSTEM READY / OFFLINE** | 即時連線狀態 |
| **CTL: 數字** | 目前連線中的控制台數量 |
| **DSP: 數字** | 目前連線中的顯示端數量 |
| **當前歌曲** | 正在播放的歌曲名稱與歌手 |

### 2.5 歌詞操作區（Cue Grid）

Cue Grid 是你控制歌詞的核心區域。每一行歌詞都像一個「Cue（提示）」，你可以：

- **點擊任一行**：立即跳轉到該行，投影端同步顯示
- **觀察 LIVE 標記**：橘色高亮的那一行就是投影端正在顯示的歌詞
- **使用進度條**：底部的進度條顯示目前播放到整首歌的哪個位置
- **按 NEXT CUE 按鈕**：底部的大按鈕可以切換到下一行（等同按空白鍵）

> 當滑鼠懸停在某一行上時，會出現「JUMP」標記，提示你可以點擊跳轉。

### 2.6 鍵盤快捷鍵

在控制台中，你可以用鍵盤快速操作：

| 按鍵 | 功能 |
|------|------|
| `↓` 或 `→` | 下一行歌詞 |
| `↑` 或 `←` | 上一行歌詞 |
| `空白鍵` | 播放 / 暫停 切換 |
| `Home` | 跳到第一行 |
| `End` | 跳到最後一行 |
| `1` - `9` | 直接跳到第 1 - 9 行 |
| `F`（顯示端） | 進入 / 退出全螢幕 |

### 2.7 即時預覽面板

即時預覽面板（Program Out）會模擬投影端實際的畫面效果，讓你不用看投影幕就能知道觀眾看到什麼：

- 顯示行數、字體大小等設定的即時效果
- 高亮色套用在當前行的效果
- 左上角顯示設定參數（行數 / 字體大小）
- 右上角有 LIVE 標記（表示正在投影中）

## 3. 顯示端設定

顯示端是投影給觀眾看的畫面。

### 3.1 開啟顯示端

有三種方式開啟顯示端：

**方式一：手動輸入同步碼**
1. 在投影電腦的瀏覽器中前往 `https://你的網址/display`
2. 畫面中央會出現同步碼輸入框
3. 輸入控制台上顯示的 6 碼同步碼
4. 輸入完畢自動連線

**方式二：使用連結**
1. 在控制台點擊「複製連結」按鈕
2. 把連結傳到投影電腦上（透過通訊軟體或 Email）
3. 在投影電腦的瀏覽器中開啟連結，自動連線

**方式三：掃描 QR Code**
1. 在控制台找到 QR Code 面板
2. 用投影電腦的手機掃描 QR Code
3. 開啟連結後自動連線

> **提示**：你也可以點擊「下載 QR」按鈕，把 QR Code 圖片存下來，列印或分享給其他人。

### 3.2 全螢幕模式

連線成功後，建議把顯示端切換到全螢幕：

1. 按鍵盤 `F` 鍵進入全螢幕
2. 再按一次 `F` 鍵退出全螢幕
3. 也可以點擊畫面底部浮動控制列上的全螢幕按鈕

> 全螢幕模式下，底部控制列和右上角連線指示器會在滑鼠靜止 3 秒後自動隱藏。移動滑鼠即可重新顯示。

> **注意**：iOS Safari 不支援全螢幕功能，全螢幕按鈕會自動隱藏。

### 3.3 顯示端浮動控制列

顯示端底部有一個浮動的控制列，提供以下功能：

| 按鈕 | 功能 |
|------|------|
| **上箭頭** | 上一行歌詞 |
| **下箭頭** | 下一行歌詞 |
| **行數指示** | 顯示「第幾行 / 共幾行」 |
| **AUTO / MANUAL** | 切換自動模式（AI 追蹤）或手動模式 |
| **全螢幕按鈕** | 進入 / 退出全螢幕 |

### 3.4 連線狀態指示

顯示端右上角有一個連線狀態指示器：

| 狀態 | 顏色 | 說明 |
|------|------|------|
| **已連接** | 綠色（閃爍） | 正常連線中，歌詞會即時同步 |
| **重連中** | 橘色（閃爍） | 連線暫時中斷，系統正在嘗試重新連接 |
| **已離線** | 紅色（靜態） | 連線失敗，歌詞停留在最後位置 |

如果畫面頂部出現紅色提示條「無法連線」，可以點擊「重試」按鈕手動重新連接。

### 3.5 歌曲資訊提示

每當切換到新歌曲時，顯示端左上角會短暫出現歌曲名稱和歌手資訊（幾秒後自動淡出），方便確認當前播放的歌曲。

## 4. 歌曲管理

### 4.1 歌曲庫介面

歌曲庫位於控制台左側（桌面版）或「歌曲」分頁（手機版）。上方顯示歌曲總數，下方是歌曲列表。你可以在歌曲庫和播放清單之間切換（點擊頂部的 **Songs** / **Playlists** 分頁）。

### 4.2 新增歌曲

有三種方式新增歌曲。在歌曲庫上方有三個按鈕：

#### 方式一：搜尋歌詞

1. 點擊「搜尋歌詞」按鈕
2. 在搜尋框輸入歌曲名稱或歌手
3. 從搜尋結果中選擇想要的歌曲
4. 系統自動填入歌名、歌手和歌詞
5. 確認後儲存

> 搜尋功能支援繁簡體中文自動轉換，輸入簡體也能找到繁體歌詞。

#### 方式二：手動輸入

1. 點擊「手動輸入」按鈕
2. 填寫以下欄位：
   - **歌名**（必填）
   - **歌手**（選填）
   - **歌詞**（必填，一行一句）
3. 點擊「ADD TRACK」按鈕儲存

**歌詞格式範例：**
```
我們呼求
主你是我的力量
你是我的盼望
在你裡面我得安息
```

> **注意**：每一行就是投影時的一個「Cue」。建議一句歌詞為一行，不要把多句放在同一行。

#### 方式三：匯入 LRC 檔案

1. 點擊「匯入 LRC」按鈕
2. 選擇你的 `.lrc` 檔案
3. 系統自動解析歌名、歌手和歌詞
4. 匯入成功後自動出現在歌曲庫

> **拖放匯入**：你也可以直接把 `.lrc` 檔案拖放到歌曲庫中的「拖放 .lrc 匯入」區域。

### 4.3 搜尋歌曲

在歌曲庫中有一個搜尋框，輸入歌名或歌手即可篩選歌曲。搜尋是即時的，輸入時結果會自動更新。

### 4.4 排序歌曲

點擊搜尋框旁邊的排序按鈕，可以循環切換排序方式：

1. **預設排序**（無排序）
2. **歌名 A-Z**（字母升序）
3. **歌名 Z-A**（字母降序）
4. **歌手 A-Z**（歌手名稱升序）
5. **歌手 Z-A**（歌手名稱降序）

### 4.5 選擇歌曲

在歌曲列表中點擊任一首歌曲，即可選為當前歌曲。選中的歌曲會以高亮顯示，並在左側出現播放圖示。同時歌詞會出現在中間的歌詞操作區。

### 4.6 匯出 LRC 檔案

如果你想匯出歌曲的歌詞，可以把滑鼠移到歌曲列表中的某首歌上，會出現下載圖示。點擊即可下載該歌曲的 `.lrc` 檔案。

### 4.7 刪除歌曲

把滑鼠移到歌曲列表中的某首歌上，點擊垃圾桶圖示。系統會跳出確認對話框，確認後即刪除。

> **注意**：刪除操作無法復原，請謹慎操作。

## 5. 播放清單

播放清單可以幫你預先安排一場聚會的歌曲順序，實際帶領時照著清單走就好。

### 5.1 建立播放清單

1. 在歌曲庫區域點擊上方的 **Playlists** 分頁
2. 點擊右上角的「+」按鈕
3. 輸入播放清單名稱
4. 從歌曲列表中勾選要加入的歌曲（可複選）
5. 勾選完畢後，點擊底部的「CREATE PLAYLIST」按鈕

### 5.2 使用播放清單

1. 切換到 **Playlists** 分頁
2. 點擊要使用的播放清單
3. 清單展開後會顯示所有歌曲
4. 點擊歌曲名稱即可選為當前歌曲

### 5.3 調整歌曲順序

在播放清單的歌曲列表中，你可以**拖曳**歌曲來重新排列順序。長按某首歌曲，拖到想要的位置即可。

### 5.4 重新命名播放清單

在播放清單詳情畫面中，點擊清單名稱文字即可進入編輯模式。修改完成後按 Enter 確認，或按 Escape 取消。

### 5.5 刪除播放清單

在播放清單詳情畫面中，點擊右上角的垃圾桶圖示。系統會跳出確認對話框，確認後即刪除整個播放清單。

> **注意**：刪除播放清單不會刪除裡面的歌曲，歌曲本身仍然保留在歌曲庫中。

## 6. AI 聽歌追蹤

AI 聽歌追蹤功能可以讓系統「聽」正在演唱的歌曲，自動辨識唱到哪一句並同步切換歌詞。適合唱詩班帶領或樂團演出，不需要專人手動操作。

### 6.1 啟用 AI 追蹤

1. 在控制台的設定區域找到「AI 自動跟歌」面板
2. 打開右側的開關
3. 瀏覽器會詢問麥克風權限，請點擊「允許」
4. 選擇正確的音訊輸入裝置（麥克風或外接音效卡）
5. 開始演唱，系統會自動辨識歌詞位置

### 6.2 選擇麥克風

啟用 AI 追蹤後，面板會展開顯示「Input Device」下拉選單。選擇你要使用的麥克風：

- **內建麥克風**：適合簡單場合
- **外接 USB 麥克風**：音質較好，推薦使用
- **Audio Interface**：專業錄音介面，音質最佳

> 如果你中途插拔了麥克風，系統會自動偵測並更新裝置列表。

### 6.3 調整增益

如果音量太小導致辨識不準確，可以調整增益（Gain）滑桿：

- **範圍**：0 到 +20 dB
- **建議**：先從 0 dB 開始，如果音量計顯示太低再逐步增加

### 6.4 觀察音量計

啟用後會出現一個專業的 dBFS 音量計，幫助你確認收音狀況：

| 顏色 | 範圍 | 意義 |
|------|------|------|
| **綠色** | -48 到 -18 dBFS | 正常音量 |
| **黃色** | -18 到 -6 dBFS | 偏高但可接受 |
| **紅色** | -6 到 0 dBFS | 過高，可能造成失真 |

> **最佳設定**：演唱時音量計大部分時間在綠色區域，偶爾觸碰到黃色區域。

### 6.5 手動校正

如果 AI 辨識到錯誤的歌詞行：

1. 直接點擊正確的歌詞行
2. 系統會立即跳轉到你點擊的位置
3. AI 會暫停追蹤幾秒鐘（冷卻時間），避免馬上又跳走
4. 冷卻時間結束後，AI 會從你校正的位置繼續追蹤

### 6.6 辨識狀態指示

面板底部會顯示 AI 的即時狀態：

- **辨識引擎**：顯示當前使用的語音辨識引擎
- **比對信心**：AI 對當前歌詞匹配的信心程度
- **最後匹配行**：AI 最近成功匹配的歌詞行號
- **STT 辨識**：即時顯示語音轉文字的結果（可以看到 AI 「聽到」了什麼）

### 6.7 進階設定

點擊 AI 面板上的齒輪圖示，可以調整進階設定：

| 設定 | 說明 | 建議值 |
|------|------|--------|
| **辨識引擎** | 選擇語音辨識服務 | 依網路環境選擇 |
| **比對門檻** | AI 需要多少信心才會切換歌詞 | 60-70%（調高 = 更嚴格，較少誤跳；調低 = 更靈敏，反應較快） |
| **手動冷卻** | 手動校正後 AI 暫停追蹤的秒數 | 3-5 秒 |

可用的辨識引擎：

| 引擎 | 特點 |
|------|------|
| **Google Cloud STT** | 辨識準確度最高，需要網路 |
| **Web Speech（免費）** | 瀏覽器內建，不需額外設定，但準確度較低 |
| **Deepgram** | 適合英文歌曲 |

### 6.8 自動 / 手動模式切換

在顯示端的浮動控制列上，有一個 **AUTO / MANUAL** 切換按鈕：

- **AUTO（綠色）**：AI 自動追蹤模式，歌詞會隨演唱自動切換
- **MANUAL（灰色）**：手動模式，需要人工操作切換歌詞

## 7. 多裝置同步

LY 系統支援一個控制台同時連接多個顯示端。

### 7.1 同步碼機制

每次開啟控制台，系統會自動產生一組 6 碼英數字同步碼（例如 `A3X9K2`）。所有輸入相同同步碼的顯示端都會同步到同一個控制台。

**同步碼的特性：**
- 由大寫英文字母和數字組成，共 6 碼
- 重新整理控制台頁面後，同步碼會保持不變（儲存在瀏覽器中）
- 你也可以透過網址參數指定同步碼，例如 `/controller?code=A3X9K2`

### 7.2 連接多個顯示端

你可以同時連接多個顯示端到同一個控制台。例如：

- 主投影幕一台
- 副螢幕一台
- 現場歌手的監看螢幕一台

所有顯示端會同步顯示相同的歌詞。在控制台的狀態列上可以看到 `DSP: 3`，表示有 3 台顯示端已連線。

### 7.3 更換同步碼

如果你需要換一組新的同步碼：

1. 在控制台點擊「新房間」按鈕
2. 系統會產生新的 6 碼同步碼
3. **所有已連線的顯示端都會斷線**，需要重新輸入新同步碼

> **使用時機**：當你不想讓之前連過的裝置繼續接收歌詞時，可以換一組新的同步碼。

### 7.4 離線恢復

如果網路暫時中斷：

- 顯示端會顯示「重連中」提示，歌詞停留在最後一次收到的位置
- 網路恢復後會自動重新連接（最多嘗試 5 次）
- 如果 5 次都失敗，會顯示「無法連線」，可以手動點擊「重試」
- 如果裝置完全離線（例如斷開 Wi-Fi），會顯示「離線模式」提示

## 8. 進階設定

### 8.1 顯示行數

控制投影端同時顯示幾行歌詞。

- **範圍**：1 - 10 行
- **建議**：3 - 4 行。太少則觀眾無法預讀下一句，太多則畫面擁擠

### 8.2 字體大小

控制投影端歌詞文字的大小。

- **範圍**：16px - 64px
- **建議**：依投影距離和螢幕大小調整。小型聚會（電視螢幕）可用 32px，大型場地（投影幕）建議 48px 以上

### 8.3 行距

控制歌詞行與行之間的間距。

- **範圍**：0.0x - 2.0x
- **預設**：0.5x
- **建議**：行距太小會讓文字擠在一起，太大則浪費畫面空間

### 8.4 高亮色

設定投影端「當前行」歌詞的顏色。提供六種預設色：

| 色名 | 色碼 | 適用場景 |
|------|------|----------|
| **Primary（烈焰橘）** | #FF6A00 | 預設，醒目有活力 |
| **Secondary（冰藍）** | #00E5FF | 冷色調，適合安靜敬拜 |
| **Green（霓虹綠）** | #00FF88 | 高對比，深色背景最清楚 |
| **Pink（粉紅）** | #FF3366 | 溫馨風格 |
| **Gold（金色）** | #FFB800 | 莊重場合 |
| **Orange（橘色）** | #FF6B35 | 溫暖活潑 |

### 8.5 背景色

自訂投影端的背景顏色。點擊色塊會開啟系統的顏色選擇器，你可以選擇任何顏色。

### 8.6 背景圖片

如果你想在投影歌詞的同時顯示背景圖片（例如教會 Logo 或風景照片）：

1. 點擊「上傳」按鈕
2. 選擇圖片檔案（支援 JPEG、PNG、WebP 格式）
3. 上傳後會顯示縮圖預覽
4. 如果要移除背景圖片，點擊「清除」按鈕

### 8.7 主題切換

提供深色和淺色兩種主題：

- **DARK（深色）**：黑底白字，適合暗室、舞台、投影環境
- **LIGHT（淺色）**：白底黑字，適合明亮環境、會議室

### 8.8 開關選項

| 選項 | 說明 |
|------|------|
| **BACKGROUND** | 開啟/關閉背景色顯示。關閉時使用純黑背景 |
| **AUTO SCROLL** | 開啟後，歌詞操作區會自動捲動到當前行 |
| **ANIMATION** | 開啟/關閉歌詞切換時的動畫效果 |

### 8.9 快速操作

在設定面板底部有兩個快速操作按鈕：

| 按鈕 | 功能 |
|------|------|
| **RESTART WS** | 重新啟動 WebSocket 連線。當連線異常時使用 |
| **BLACKOUT** | 清除當前歌曲，投影端回到空白畫面。適合在歌曲之間的過場使用 |

## 9. OBS 整合指南

如果你使用 OBS Studio 進行直播或錄影，可以把 LY 的歌詞畫面擷取進 OBS。

### 9.1 使用 Clean Output 模式

LY 提供一個特殊的「Clean Output」模式，專為 OBS 或 VJ 軟體設計：

- **純黑背景**（#000000），沒有任何介面元素
- 只顯示歌詞文字
- 不會顯示連線狀態、控制列等 UI 元素
- 適合搭配 OBS 的色鍵（Chroma Key）或視窗擷取使用

**啟用方式**：在顯示端的網址後面加上 `?mode=clean`

```
https://你的網址/display?mode=clean&code=A3X9K2
```

> `code=A3X9K2` 是你的同步碼，請替換為實際的同步碼。

### 9.2 在 OBS 中設定

**步驟：**

1. 開啟 OBS Studio
2. 在「來源」區域點擊「+」，選擇「瀏覽器」
3. 在 URL 欄位填入：
   ```
   https://你的網址/display?mode=clean&code=你的同步碼
   ```
4. 寬度設為 `1920`，高度設為 `1080`（或你的直播解析度）
5. 勾選「當場景非作用中時關閉來源」（節省資源）
6. 點擊「確定」

**建議進階設定：**
- 如果你需要透明背景效果，可以在「瀏覽器」來源的屬性中勾選「使用自訂幀率」並設為 30fps
- 在「濾鏡」中加入「色鍵」濾鏡，以黑色為鍵色，這樣歌詞就會像字幕一樣疊加在其他畫面上

### 9.3 透過 OBS + DistroAV（NDI）輸出到 Resolume

如果你使用 Resolume Arena 做 VJ 演出，可以透過 OBS 的 NDI 外掛把歌詞畫面傳送到 Resolume：

1. **安裝 DistroAV 外掛**：前往 [DistroAV GitHub](https://github.com/DistroAV/DistroAV) 下載並安裝 OBS NDI 外掛
2. **在 OBS 中啟用 NDI 輸出**：
   - 前往「工具」選單 > 「NDI Output Settings」
   - 勾選「Main Output」
   - 設定輸出名稱（例如 `LY-Lyrics`）
3. **在 Resolume 中接收**：
   - 新增一個圖層
   - 在「Sources」中找到 NDI 來源
   - 選擇 `LY-Lyrics`（或你設定的名稱）
   - 調整大小和位置

> **注意**：NDI 傳輸需要發送端和接收端在同一個區域網路中。

## 10. 常見問題

### 連線問題

**Q：顯示端無法連線怎麼辦？**

請依序檢查：
1. 控制台和顯示端是否在**同一個網路**（同一個 Wi-Fi）
2. 控制台網頁是否**還開著**（關掉控制台就無法同步）
3. 同步碼是否**正確**（注意大小寫，系統會自動轉為大寫）
4. 嘗試重新整理顯示端頁面
5. 嘗試在控制台點擊「RESTART WS」重新連接

**Q：歌詞不同步、有延遲怎麼辦？**

1. 檢查網路品質（延遲通常在 100ms 以內，正常使用感覺不到）
2. 如果使用公共 Wi-Fi，可能有較高延遲。建議使用手機熱點或獨立路由器
3. 在控制台設定中點擊「RESTART WS」重新建立連線

**Q：連線突然斷掉了？**

- 系統會自動嘗試重新連接（最多 5 次）
- 顯示端畫面頂部會出現橘色「重連中」提示
- 如果重連失敗，會顯示紅色「無法連線」，可以點擊「重試」按鈕

### 歌曲管理問題

**Q：如何匯入 LRC 檔案？**

有兩種方式：
1. 點擊歌曲庫上方的「匯入 LRC」按鈕，在彈出視窗中選擇檔案
2. 直接把 `.lrc` 檔案拖放到歌曲庫中的「拖放 .lrc 匯入」虛線框區域

**Q：匯入 LRC 失敗？**

請確認：
- 檔案副檔名是 `.lrc`
- 檔案內容是標準 LRC 格式
- 檔案內至少有一行歌詞

**Q：可以匯出歌曲嗎？**

可以。在歌曲列表中把滑鼠移到歌曲上，點擊出現的下載圖示，即可匯出為 `.lrc` 檔案。

### AI 聽歌追蹤問題

**Q：AI 辨識不準確怎麼辦？**

1. **環境音要清楚**：麥克風離音源近一點，減少背景噪音
2. **調整增益**：如果音量計顯示太低，適當增加增益
3. **手動校正**：如果 AI 跳錯行，直接點擊正確的歌詞行
4. **調整比對門檻**：在進階設定中降低門檻值可以提高靈敏度，但可能增加誤判
5. **選擇合適的辨識引擎**：Google Cloud STT 通常準確度最高

**Q：瀏覽器要求麥克風權限，安全嗎？**

安全的。LY 只會在你啟用 AI 追蹤時使用麥克風，音訊只用於語音辨識比對，不會錄音也不會傳到外部伺服器（視辨識引擎而定，Web Speech 使用瀏覽器內建功能）。

**Q：麥克風權限被拒絕了怎麼辦？**

1. 點擊瀏覽器網址列左側的鎖頭圖示
2. 找到「麥克風」權限設定
3. 改為「允許」
4. 重新整理頁面

### 投影與 OBS 問題

**Q：投影端背景不是純黑怎麼辦？**

- 確認在設定中把 BACKGROUND 開關**關閉**
- 或是使用 Clean Output 模式（網址加上 `?mode=clean`）

**Q：OBS 中的瀏覽器來源是白色/空白？**

1. 確認 URL 中的同步碼是否正確
2. 確認控制台是否還在運行
3. 嘗試在 OBS 中「刷新」瀏覽器來源
4. 確認 OBS 的瀏覽器來源寬高設定正確（建議 1920x1080）

### 裝置與瀏覽器問題

**Q：支援哪些瀏覽器？**

| 瀏覽器 | 支援程度 |
|--------|----------|
| **Chrome**（推薦） | 完整支援所有功能 |
| **Edge** | 完整支援 |
| **Safari** | 支援，但不支援全螢幕功能 |
| **Firefox** | 基本支援 |

**Q：可以用手機操作控制台嗎？**

可以。LY 的控制台支援手機操作，會自動切換為手機版介面。不過建議在平板或電腦上操作，畫面較大，操作更方便。

**Q：投影端可以用手機嗎？**

可以。但投影端通常接在投影機或大螢幕上，建議使用電腦瀏覽器以獲得最佳顯示效果。
