# 使用手冊

## 快速開始

### 第一次使用

1. **建立帳號**
   - 訪問 `https://ly.app`
   - 點擊「註冊」
   - 使用電子郵件或 Google 登入

2. **新增第一首歌**
   - 點擊「新增歌曲」
   - 輸入歌名、歌手
   - 貼上歌詞 (一行一句)
   - 點擊「儲存」

3. **開始同步**
   - 在電腦上開啟控制端
   - 在手機/平板上開啟顯示端
   - 輸入同步碼或掃描 QR Code
   - 開始使用！

---

## 功能說明

### 歌詞管理

#### 新增歌曲

1. 點擊「新增歌曲」按鈕
2. 填寫資訊:
   - **歌名** (必填)
   - **歌手** (選填)
   - **歌詞** (必填，一行一句)
3. 點擊「儲存」

**歌詞格式範例:**
```
我聽見雨滴
落在青青草地
我遠方的一位
那個少年
```

#### 編輯歌曲

1. 在歌曲列表中找到目標歌曲
2. 點擊「編輯」圖示
3. 修改內容
4. 點擊「儲存」

#### 刪除歌曲

1. 在歌曲列表中找到目標歌曲
2. 點擊「刪除」圖示
3. 確認刪除

---

### 播放列表

#### 創建播放列表

1. 點擊「播放列表」
2. 點擊「新建播放列表」
3. 輸入名稱
4. 添加歌曲

#### 管理播放列表

- **拖曳排序**: 長按歌曲並拖曳
- **移除歌曲**: 點擊歌曲旁的「×」
- **刪除播放列表**: 點擊「刪除」按鈕

---

### 控制端操作

#### 基本控制

| 按鈕 | 功能 |
|------|------|
| `◀◀` | 回到第一句 |
| `◀` | 上一句 |
| `▶` | 下一句 |
| `▶▶` | 跳到最後一句 |

#### 快捷鍵

| 按鍵 | 功能 |
|------|------|
| `←` / `→` | 上一句 / 下一句 |
| `↑` / `↓` | 上一句 / 下一句 |
| `Space` | 暫停 / 繼續 |
| `F` | 全螢幕切換 |

#### 跳轉到指定行

1. 點擊歌詞預覽區中的任意一行
2. 系統自動跳轉並同步到所有顯示端

---

### 顯示端設定

#### 顯示設定

| 設定 | 說明 | 範圍 |
|------|------|------|
| 顯示行數 | 同時顯示幾行歌詞 | 1-10 行 |
| 字體大小 | 歌詞文字大小 | 小 / 中 / 大 |
| 行距 | 歌詞行與行之間的距離 | 1.0 - 3.0 |

#### 主題設定

- **深色模式**: 適合暗室或舞台
- **淺色模式**: 適合明亮環境
- **自訂背景**: 可上傳背景圖片

---

### 多裝置同步

#### 連接方式

**方式一：同步碼**
1. 控制端顯示 6 位數同步碼
2. 顯示端輸入同步碼
3. 連線建立

**方式二：QR Code**
1. 控制端顯示 QR Code
2. 顯示端掃描 QR Code
3. 連線建立

#### 連線狀態

| 狀態 | 說明 |
|------|------|
| ● 已連線 (2) | 2 個顯示端已連線 |
| ○ 連線中 | 正在建立連線 |
| ○ 已斷線 | 連線中斷，嘗試重連 |

---

### AI 聽歌辨識 (Phase 3)

#### 啟動 AI 辨識

1. 選擇要演唱的歌曲
2. 點擊「啟動 AI 聽歌」
3. 允許麥克風權限
4. 開始播放音樂
5. 系統自動識別並同步歌詞

#### 校正 AI 結果

如果 AI 識識錯誤：
1. 手動點擊正確的歌詞行
2. AI 將學習並改善

---

### NDI 輸出 (Phase 2)

#### 設定 NDI 輸出

1. 點擊「NDI 設定」
2. 啟用 NDI 輸出
3. 設定輸出名稱 (預設: LY-Lyrics)
4. 設定背景為透明
5. 儲存設定

#### 在 Resolume Arena 中使用

1. 新增「Source」
2. 選擇 NDI
3. 選擇 `LY-Lyrics`
4. 調整大小與位置

## 常見問題

### Q: 為什麼顯示端無法連線？

**A:** 請確認：
1. 兩裝置在同一網路
2. 控制端網頁已開啟
3. 同步碼正確
4. 防火牆未阻擋

### Q: 歌詞不同步怎麼辦？

**A:**
1. 檢查網路連線
2. 重新整理顯示端頁面
3. 重新連線

### Q: 如何匯入 LRC 檔案？

**A:**
1. 準備 LRC 格式歌詞檔案
2. 新增歌曲時，點擊「匯入 LRC」
3. 選擇檔案
4. 系統自動解析

### Q: AI 辨識不準確？

**A:**
1. 確保環境音樂清晰
2. 降低背景噪音
3. 手動校正讓 AI 學習
4. 使用有時間戳的歌詞

### Q: 支援哪些瀏覽器？

**A:**
- Chrome (推薦)
- Safari
- Edge
- Firefox (部分功能)
