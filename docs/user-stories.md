# 用戶故事

## 用戶角色定義

| 角色 | 描述 | 主要目標 |
|------|------|---------|
| **表演者** | 需要在舞台或練習時查看歌詞的歌手 | 清楚看到當前歌詞行 |
| **控制者** | 負責控制歌詞進度的人員 | 精準控制歌詞跳轉 |
| **直播主** | 需要將歌詞疊加到直播畫面 | NDI 輸出到 OBS/Resolume |
| **樂團成員** | 練團時需要查看同步歌詞 | 多裝置同步顯示 |

---

## 核心用戶故事

### US1: 歌詞管理

#### US1.1 新增歌曲
**作為** 表演者
**我想要** 新增一首新歌曲到系統中
**以便於** 我可以準備好演唱所需的歌詞

**驗收標準:**
- [ ] 可以輸入歌名
- [ ] 可以輸入歌手名稱
- [ ] 可以輸入歌詞 (一行一句)
- [ ] 歌詞儲存後可在列表中看到
- [ ] 支援多行歌詞輸入

**優先級:** P0 | **狀態:** 🔴 Not Started

---

#### US1.2 編輯現有歌曲
**作為** 表演者
**我想要** 編輯已儲存的歌曲資訊
**以便於** 修正歌詞錯誤或更新資訊

**驗收標準:**
- [ ] 可以從列表選擇歌曲編輯
- [ ] 可以修改歌名、歌手、歌詞
- [ ] 可以取消編輯不儲存
- [ ] 儲存後更新顯示

**優先級:** P0 | **狀態:** 🔴 Not Started

---

#### US1.3 刪除歌曲
**作為** 表演者
**我想要** 刪除不需要的歌曲
**以便於** 保持歌詞庫整潔

**驗收標準:**
- [ ] 可以刪除歌曲
- [ ] 刪除前有確認提示
- [ ] 刪除後從列表移除

**優先級:** P0 | **狀態:** 🔴 Not Started

### US5: 多裝置同步

#### US5.1 控制端與顯示端同步
**作為** 控制者
**我想要** 在控制端操作時，顯示端即時更新
**以便於** 為表演者提供歌詞提示

**驗收標準:**
- [ ] 控制端切換歌曲，顯示端同步切換
- [ ] 控制端點擊下一句，顯示端同步更新
- [ ] 同步延遲 < 100ms
- [ ] 支援多個顯示端同時連線

**優先級:** P0 | **狀態:** 🔴 Not Started

---

**我想要** 在任何裝置上都能正常使用

**驗收標準:**
- [ ] 桌面版 (1920px+) 正常顯示
- [ ] 平板版 (768px-1024px) 正常顯示
- [ ] 手機版 (320px-767px) 正常顯示

**優先級:** P0 | **狀態:** 🔴 Not Started
