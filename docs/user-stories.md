# 用戶故事

## 用戶角色定義

| 角色 | 描述 | 主要目標 |
|------|------|---------|
| **表演者** | 需要在舞台或練習時查看歌詞的歌手 | 清楚看到當前歌詞行 |
| **控制者** | 負責控制歌詞進度的人員 | 精準控制歌詞跳轉 |
| **直播主** | 需要將歌詞疊加到直播畫面 | NDI 輸出到 OBS/Resolume |
| **樂團成員** | 練團時需要查看同步歌詞 | 多裝置同步顯示 |

**我想要** 新增一首新歌曲到系統中
**以便於** 我可以準備好演唱所需的歌詞

**驗收標準:**
- [x] 可以輸入歌名
