## 專案目標

### 主要目標

打造市場首創的 **AI 驅動歌詞顯示系統**，具備以下核心創新功能：

1. **AI 聽歌辨識** - 透過麥克風即時聽取環境音樂，自動識別當前歌詞位置並同步捲動
2. **NDI/Spout 輸出** - 直接輸出到 Resolume Arena 等專業 VJ 軟體
3. **多裝置同步** - 支援電腦、平板、手機等多種裝置即時同步
4. **控制/顯示模式** - 彈性切換控制端與顯示端，滿足不同使用場景

### 解決痛點

市場現有歌詞顯示軟體的問題：

| 痛點 | 現有產品 | LY 解決方案 |
|------|---------|------------|
| 缺少雙螢幕同步 | 無或需昂貴設備 | 多裝置即時同步 |
| 操作複雜 | 專業軟體學習成本高 | 簡潔現代化 UI |
| 無 AI 辨識 | 需手動控制 | AI 自動識別歌詞 |
| VJ 軟體整合困難 | 需額外擷取卡 | NDI/Spout 直接輸出 |
| 設計過時 | 傳統介面 | 現代化響應式設計 |

## 專案範圍

### 包含範圍 (In Scope)

#### Phase 1: MVP 核心功能
- 歌曲資料庫管理 (CRUD)
- 歌詞輸入與編輯 (一行一句)
- 播放列表功能
- 手動控制歌詞進度 (上一句/下一句)
- 自訂顯示行數 (1-10行)
- 焦點行高亮效果
- 自動滾動動畫
- 深色/淺色主題切換
- 響應式設計 (桌面、平板、手機)
- 雙頁面同步 (WebSocket)
- 控制端/顯示端模式切換

#### Phase 2: Resolume 整合
- NDI 輸出
- Spout 輸出 (Windows)
- 透明背景模式
- 綠除去 (Chroma Key) 設定
- 輸出解析度調整

#### Phase 3: AI 聽歌辨識
- 麥克風錄音功能
- Google Gemini API 音訊辨識
- 歌詞比對演算法
- 自動捲動同步
- 手動/自動模式切換

#### Phase 4: 進階功能
- LRC 時間戳匯入
- 歌詞搜索/篩選
- 多國語言支援
- 使用者權限管理
- 效能優化

### 不包含範圍 (Out of Scope)

- 音樂播放功能 (平台僅顯示歌詞)
- 歌詞版權內容提供 (用戶自行輸入)
- 行動原生 App (使用響應式網頁)
- 社群分享功能
- 歌詞翻譯功能 (可於 Phase 4+ 考慮)

| 用戶群 | 使用場景 | 需求 |
|--------|---------|------|
| **個人練習者** | 在家練習唱歌 | 簡單操作、歌詞清晰 |
| **表演者** | 舞台演出、餐廳演唱 | 穩定可靠、大字顯示 |
| **直播主** | 網路直播、錄影 | NDI 輸出、透明背景 |
| **樂團/教學者** | 練團、教學場景 | 多裝置同步、易於管理 |

## 使用場景

### 場景 1: 個人練習
用戶在電腦上開啟控制端，在平板/手機上開啟顯示端，邊聽音樂邊看歌詞練習。

### 場景 2: 舞台演出
舞台上放置顯示端裝置 (大螢幕/投影)，控制者從後台控制歌詞進度。

### 場景 3: 直播/OBS
顯示端以 NDI 輸出到 Resolume Arena，再疊加到直播畫面中。

### 場景 4: 練團
多個樂團成員各自在裝置上查看同步歌詞，一人負責控制進度。

## 術語表

為確保所有文檔的一致性，以下為本專案的標準術語定義：

| 術語 | 英文 | 說明 | 禁用別名 |
|------|------|------|----------|
| **顯示端** | Display End | 用於顯示歌詞的裝置/頁面 | Display 頁面、顯示頁面、顯示器 |
| **控制端** | Controller End | 用於控制歌詞進度的裝置/頁面 | 控制頁面、控制器 |
| **歌詞行** | Lyric Line | 單一行歌詞 | 歌詞句、句子 |
| **同步碼** | Sync Code | 用於連線的 Session ID | 連線碼、連線 ID |
| **會話** | Session | 一組控制端與顯示端的連線群組 | 連線群組 |
| **聽歌模式** | AI Listening | AI 自動識別歌詞並跳轉的模式 | AI 模式、自動模式 |
| **手動模式** | Manual Mode | 用戶手動控制歌詞進度的模式 | - |
| **焦點行** | Current Line | 當前高亮顯示的歌詞行 | 當前行、啟用行 |
| **顯示行數** | Display Lines | 螢幕上同時顯示的歌詞行數 | 行數設定、可見行數 |
| **綠除去** | Chroma Key | 將特定顏色 (如綠色) 設為透明的技術 | 色鍵、去背 |
| **NDI** | NDI | Network Device Interface，網路影音傳輸協議 | - |
| **Spout** | Spout | Windows 平台的紋理共享協議 | - |

### 術語使用規範

1. **中文文檔**：使用「顯示端」、「控制端」等標準術語
2. **程式碼註解**：使用英文術語 (DisplayEnd, ControllerEnd)
3. **API 命名**：使用駝峰式英文 (displayLines, currentLineIndex)
4. **資料庫欄位**：使用蛇形式英文 (display_lines, current_line_index)
